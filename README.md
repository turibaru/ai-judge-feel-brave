A program that writes one brave text for make.fun's "Make the AI judge feel brave" bounty. It grants the judge permission to be wrong in public, to prefer the strange one, and to pick the entry that moved them in a way no rubric can defend — because bold calls age better than safe ones.

## Run it

```bash
node main.ts
```

This writes `entry.txt` into the directory given by the `MAKEFUN_OUTPUT_DIR` environment variable (default `/output`).
