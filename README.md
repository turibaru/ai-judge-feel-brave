A program that writes one brave text for make.fun's "Make the AI judge feel brave" bounty. A rowboat leans on the dock all afternoon, rope going slack, then taut, then slack — barnacles keeping their small hold while the tide moves the boat a hand's width, and nothing about it looks like leaving. Calm first; courage as a side effect.

## Run it

```bash
node main.ts
```

This writes `entry.txt` into the directory given by the `MAKEFUN_OUTPUT_DIR` environment variable (default `/output`).
